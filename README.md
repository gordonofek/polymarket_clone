# Polymarket Clone

Maven multi-module project:

| Folder         | Maven module | What it is                                 |
|----------------|--------------|--------------------------------------------|
| `EngineModule` | `engine`     | Core logic + XML loading (JAXB)            |
| `web`          | `web`        | Servlets, packaged as a WAR for Tomcat     |
| `UIModule`     | `ui`         | JavaFX client that talks to the server     |

All libraries (JavaFX, JAXB, Gson, Servlet API) are downloaded by Maven – nothing to configure in
*Project Structure*.

## Setup (IntelliJ IDEA Ultimate)

1. Clone the repo and open the folder with **File → Open**. IntelliJ detects `pom.xml` and imports everything.
2. **JDK 25** – if IntelliJ asks, pick/download a JDK 25 for the project.
3. **Tomcat 10.0.27** – download the zip from <https://tomcat.apache.org/download-10.cgi>, extract it anywhere, then
   *Settings → Build, Execution, Deployment → Application Servers → + → Tomcat Server*,
   point it at the extracted folder and name it exactly **`Tomcat 10.0.27`**.

## Running

1. Run **Tomcat Server** – deploys `web:war exploded` at `http://localhost:8080/guess-market/`.
2. Run **Client** – the JavaFX UI.

From the command line (no Maven install needed, the wrapper downloads it):

```
mvnw.cmd package            # build everything (web/target/guess-market.war)
mvnw.cmd -pl UIModule javafx:run
```

## Rules

- Need a new library? Add a `<dependency>` to the module's `pom.xml` (version in the root `pom.xml`) and
  click **Load Maven Changes** in IntelliJ. Don't add jars through *Project Structure* – that's overwritten on the next Maven import.
- `.idea/` and `*.iml` are generated by IntelliJ from the poms and not committed.
- New run configurations: tick **Store as project file** so they're saved under `.run/`.
